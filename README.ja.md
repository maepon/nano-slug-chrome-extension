# Nano Slug Generator

[English](README.md)

投稿のタイトルを選択すると、WordPress向けの英語のslug候補を最大3つ表示します。番号キーを押すだけでコピーできます。タイトルは日本語のほか、韓国語や中国語などにも対応しています。処理はすべて、Chrome内蔵AIで端末の中で行います。

## インストール

<!-- TODO: 公開後に Chrome ウェブストアのリンクを足す -->

Chrome ウェブストアにはまだ公開していません。今すぐ試す場合は、ソースから読み込んでください。

1. このリポジトリをダウンロードまたはクローンする。
2. `chrome://extensions` を開き、**デベロッパーモード**をオンにする。
3. **パッケージ化されていない拡張機能を読み込む**を押し、リポジトリのフォルダを選ぶ。

## 使い方

1. ページ上のタイトルを選択する。
2. **Alt+S**（Macは **Option+S**）を押すか、右クリックして**選択テキストからslugを生成**を選ぶ。
3. **1〜3キー**を押すか、候補をクリックしてコピーする。**Esc** で閉じる。

ショートカットは `chrome://extensions/shortcuts` で変更できます。

## 候補の種類

| 種類 | 作り方 | 必要なもの |
|---|---|---|
| 直訳 | タイトルを翻訳し、冠詞や前置詞などを取り除く | Chrome の Translator API |
| 短縮 | 同じ翻訳から、さらに語を減らす。直訳より短くならない時は出さない | Chrome の Translator API |
| AI | Gemini Nano が言い換えたslugを提案し、空いている番号を埋める | Chrome の Prompt API |

タイトルがすでに英語なら翻訳しません。`macOS` や `Chrome` のように元のタイトルにラテン文字で書かれた語は、できるだけ残します。`not`、`no`、`without`、`vs` などの語は消しません。

## 動作環境

- **直訳と短縮:** デスクトップ版 Chrome 138 以降。
- **AI（なくても使えます）:** [Gemini Nano のハードウェア要件](https://developer.chrome.com/docs/ai/get-started)も満たす必要があります。執筆時点の主な要件は次のとおりです。
  - Windows 10/11、macOS 13以降、Linux、または Chromebook Plus の ChromeOS
  - Chrome のプロファイルがあるボリュームに 22 GB 以上の空き容量
  - VRAM が 4 GB を超える GPU、または RAM 16 GB 以上かつ4コア以上の CPU
  - 初回のダウンロード時に、従量制でないネットワーク接続

モバイル版のブラウザには対応していません。AIが使えない環境でも、直訳と短縮の候補は出ます。

## モデルのダウンロード

言語判定、翻訳、AIのモデルは、初めて使う時に Chrome がダウンロードすることがあります。その時はボタンを表示し、押した時だけダウンロードを始めます。AIのモデルは数GBあります。

## 言語

**タイトルの言語:** タイトルの文字とブラウザの言語設定（`chrome://settings/languages`）から判定します。

- かなとハングルは、文字だけで判定します。
- 漢字やキリル文字などの文字は、言語設定も使います。それでも決まらない時は Language Detector を使います。
- ラテン文字のタイトルは、英語以外のラテン文字の言語が言語設定にある時だけ、他の言語かを調べます。それ以外は英語として扱います。

**フランス語などのラテン文字の言語を翻訳するには、その言語をブラウザの言語設定に追加してください。** 追加しないと翻訳されず、元の言語のままslugになります。

**表示言語:** 画面の文言は Chrome の表示言語に合わせます。対応しているのは英語と日本語で、それ以外の表示言語では英語で出ます。表示言語はslugに影響しません。

## プライバシー

- この拡張はネットワーク通信を行わず、タイトルやslugを保存しません。
- タイトルは Chrome の内蔵APIで処理します。[Chrome のドキュメント](https://developer.chrome.com/docs/ai/get-started)には、「No data is sent to Google or any third party when using the model.」（モデルの使用時に、データが Google や第三者に送信されることはない）とあります。
- モデルは Chrome がネットワークからダウンロードします。[モデルのダウンロード](#モデルのダウンロード)を参照してください。

詳しくは[プライバシーポリシー](PRIVACY_POLICY.md#プライバシーポリシー)を参照してください。

## 権限

| 権限 | 使う理由 |
|---|---|
| `activeTab` | 起動した時に、開いているタブの選択範囲を読むため |
| `scripting` | 起動した時に、そのタブへポップアップを表示するため |
| `contextMenus` | 右クリックメニューに項目を追加するため |
| `clipboardWrite` | 選んだslugをコピーするため |

`<all_urls>` は使いません。起動するまで、ページ上では動きません。

## 制限事項

- 動作を確認しているのは WordPress のブロックエディタです。クラシックエディタや他のCMSは未確認です。
- 使うのは選択範囲の先頭200文字までです。
- 他の言語の短いタイトルは、その言語を設定に入れていても英語として扱われることがあります。
- タイトルの言語を判定できない時や、Chrome がその言語から翻訳できない時は、slugを表示しません。
- 他の拡張機能と同じく、`chrome://` のページや Chrome ウェブストアでは動きません。
